LuckyNumber V8.01 • Calculate Non-Blocking Pro
Base: V8.00 Profile Delete Transaction Pro
Scope: Prevent Calculate/5-digit keypad UI from blocking the iPhone/PWA main thread.

ROOT CAUSE CONFIRMED
- V8.00 Calculate foreground path called saveState().
- saveState() JSON.stringify()'d the complete state and synchronously wrote the MAIN localStorage payload.
- Cost grows with History / WF / AI payload size, so an otherwise-rendered Calculate screen can feel briefly frozen.

FIX
- Calculate button -> saveCalculatorUiFast() (compact boot snapshot only).
- Clear button -> saveCalculatorUiFast().
- Every numeric keypad digit/delete -> saveCalculatorUiFast().
- Automatic calculation after digit #5 -> saveCalculatorUiFast().
- Load historical result into Calculate -> saveCalculatorUiFast().
- Compact boot snapshot timestamp now uses Date.now() so immediate close/reopen restores the newest UI state.
- Corrected compact lastInput fallback to 5 slots.
- Full History/WF/AI durable mutation paths remain unchanged.
