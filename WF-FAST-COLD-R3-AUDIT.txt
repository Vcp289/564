LuckyNumber V6.10.40-R3 — WF Fast Cold Import Audit

Performance-only changes:
1) WF evolutionary status scoring uses precomputed L cell paths instead of allocating full findLResults objects for every candidate/sample.
2) Candidate fitness is memoized by immutable formulaKey within each target draw; surviving elites are not rescored against identical train/test samples.
3) Classic/AI formula grids are each built once per WF target and reused in stored WF records.
4) Cold imports throttle DOM progress writes and event-loop yields while still keeping iPhone UI responsive.
5) WF progress text now includes its own true percentage (done/total), separate from overall import progress.

Unchanged methodology / safety:
- WF population 48
- WF generations 8
- elite size 10
- AI history windows/weights unchanged
- strict prior-only source table and training memory rules unchanged
- no Legacy evidence promoted to Verified Live
- no current/future result enters the target draw training set
- deterministic seed/ranking/evolution operators unchanged
