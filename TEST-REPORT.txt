LuckyNumber V7.20.86r • DETERMINISTIC ATOMIC RANKING PRO
Base: V7.20.86q AI Unified Final Pro

ROOT CAUSE FIX
- Full Rebuild previously published WF/AI Profile-by-Profile while Profile Ranking remained readable.
- Ranking could therefore observe mixed engine generations and different trusted row readiness.
- 7/14/30 day ranking windows could also anchor to each Profile's latest hydrated trusted row.

STRUCTURAL CHANGES
1) Ranking generation read barrier
   - Full Rebuild freezes the last complete Profile Ranking before any AI/WF cache is cleared.
   - While rebuild status != done, every Profile Ranking consumer reads that frozen generation.
   - No mixed old/new Profile generations can be displayed.

2) One shared ranking calendar anchor
   - Every Profile in the same ranking generation uses the same targetDate.
   - 7/14/30/90/180 windows no longer move independently with each Profile's latest hydrated row.

3) Atomic publish after all Profiles complete
   - WF + AI L + AI GL + P19 + X3 complete for all Profiles first.
   - Then Profile Ranking is computed fresh and published once as one authority snapshot.

4) Repeatability Audit gate
   - Final Profile Ranking is recomputed 7 times from the same final state.
   - rank order + rankScore + trusted rate + samples + hits + confidence + anchor must hash identically.
   - Rebuild cannot reach 100% if the 7 runs disagree.

5) Source/engine identity
   - Authority snapshot records source fingerprint, target date, engine signature, generation, digest.
   - Same source + same engine + same target date resolves to the same authority generation.

INVARIANT
Same source dataset + same engine signature + same target date = same Profile Ranking.
