LuckyNumber V8.14.17 • Pro Nav Idle R1 • iOS Pro
Base: V8.14.16 Update Core R1

GOAL
- Bottom-tab navigation must never show a full-page loading/sync message.
- Opening Calculate / AI / History / Analysis / Settings must not start AI/WF/P19/Analysis repair jobs.
- Returning to a rendered tab is a pure snapshot/cache DOM swap.
- Normal healthy launch must not wake a deferred 15-second WF maintenance job.
- X3 payload ready must not hydrate/recompute/redraw merely because the module loaded.

CHANGES
1. Removed fastViewPlaceholder and aria-busy navigation shell.
2. First-ever tab visit renders destination content directly; no requestAnimationFrame + setTimeout navigation gate.
3. render(), refreshCurrentView(), applyFastViewHtml() no longer schedule Missing-AI/P19 recovery.
4. unifiedP19X3HistoryBundles is read-only on render; missing bundles remain pending until mutation/manual repair.
5. AI-standard snapshot reads no longer schedule summary rebuilds.
6. Analysis snapshot read no longer ensureRows/self-heal on navigation.
7. Analysis cold-entry no longer hydrates all Profiles or performs post-paint refresh.
8. Healthy launch no longer schedules the 15s maintenance wake-up; only a genuinely unfinished WF job does.
9. x3-pro-ready no longer hydrates model data or redraws the current page.
10. Save/Edit/Delete/Import/Manual Refresh/Rebuild authority is preserved.
