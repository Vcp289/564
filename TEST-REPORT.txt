LuckyNumber V8.14.20 • Simple Use R1 — TEST REPORT

GOAL
Normal use is simple and event-driven:
- Calculate: use calculator / find L only.
- AI: view persisted AI status/results; opening page does not train/rebuild.
- History: view old rows and save rapidly/continuously; UI/History first.
- Analysis: read-only snapshot/summary on navigation.
- Settings: control/manual actions only.

CHANGES FROM V8.14.19
1. Normal post-paint startup no longer runs bootstrapPersistentState, async AI/X3 hydration, or History rescue.
2. Calculator profile switch restores synchronous persisted mirrors only and paints once; no async AI/X3/P19 hydration is started.
3. Navigation remains cache/snapshot-only.
4. Save core remains UI-first/History-first; exact-row WF remains detached background work.
5. iPhone Save touch guard retained.
6. Formula/engine modules were not modified.
