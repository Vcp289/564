# LuckyNumber Pro V4.7

พัฒนาจาก V4.3 โดยคงหน้าตาและฟังก์ชันเดิม พร้อมปรับระบบเลขออกจริง:
- เปลี่ยนจากเลขออกจริง 5 หลักเป็นเลขออกจริง 3 หลัก
- เลือกชื่อเจ้าของข้อมูลจาก 5 ชื่อที่ตั้งไว้ในแอป
- ประวัติแสดงวันที่ เลข 3 หลัก ชื่อ และหมายเหตุ
- แตะรายการเพื่อดูรายละเอียด แก้ไข หรือลบ
- ป้องกันรายการซ้ำโดยตรวจตามวันที่และชื่อ
- ข้อมูลเก็บใน Local Storage และรวมอยู่ในไฟล์สำรอง JSON


## เพิ่มใน V4.7
- บันทึกตาราง 15 ช่องแยกตามวันที่และรายชื่อเดียวกับด้านบน
- เก็บเลขตั้งต้น ตารางเต็ม และผลเลข L ของวันนั้น
- กรอกเลขจริง 3 หลักภายหลัง แล้วเปรียบเทียบ ตรง / เลขกลับ / ไม่พบ อัตโนมัติ
- เปิดดูตารางและผลย้อนหลังได้
- ข้อมูลตารางรวมอยู่ในการสำรองและนำเข้า JSON


## V4.7
- หน้าเลขออกจริง 3 หลักใช้แท็บรายชื่อ 5 สีชุดเดียวกับตารางย้อนหลัง
- กดชื่อใดจะแสดงเฉพาะเลขออกจริงของชื่อนั้น
- จำนวนรายการ ปุ่มบันทึก แถบสีการ์ด และป้ายชื่อเปลี่ยนตามชื่อที่เลือก
