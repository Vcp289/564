# LuckyNumber V4.18 — Load Last Result

ปรับเฉพาะหน้า Calculate:
- เพิ่มปุ่ม LOAD LAST RESULT ใต้ปุ่มเลือกชื่อ
- เรียกผลย้อนหลังล่าสุดของชื่อที่เลือกเท่านั้น
- นำเลขจริง 3 ตัวใส่ช่อง 1–3 และเลขจริง 2 ตัวใส่ช่อง 4–5
- คำนวณตาราง 15 ช่องอัตโนมัติทันที
- ปุ่มจะแสดงวันที่และเลขที่จะเรียกก่อนกด
- ถ้ายังไม่มีข้อมูล 3 ตัวและ 2 ตัวครบ ปุ่มจะถูกปิดใช้งาน
- ไม่เปลี่ยนโครงสร้างหน้า Weekly, History, Analysis และ Settings
