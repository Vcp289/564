# LuckyNumber V5.3.1 Import Sandbox

ฐานระบบ: V5.3 History Backup Protection

เพิ่มการนำเข้ารูปแบบแยกส่วน:
- เลือกรูปครั้งละ 1 รูป
- ย่อภาพก่อน OCR เพื่อลดหน่วยความจำบน iPhone
- OCR โหลดเมื่อใช้งานเท่านั้น
- แสดง Preview และให้แก้วันที่/เลข 3 ตัว/เลข 2 ตัวก่อนบันทึก
- OCR ล้มเหลว ผู้ใช้ยังกรอกเองและยืนยันได้
- ไม่แตะ History หรือ AI จนกด “ยืนยันบันทึกเข้า History”
- หลังยืนยันจึงอัปเดต History, ตาราง และ AI โดยแยก try/catch ไม่ให้ส่วนหนึ่งทำให้ข้อมูลหลักหาย

หมายเหตุ: OCR ครั้งแรกต้องใช้อินเทอร์เน็ต และภาพ HEIC บางภาพอาจเปิดไม่ได้ใน Safari ให้ใช้ Screenshot/JPG/PNG แทน
