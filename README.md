# LuckyNumber V4.28 — Auto Close 2-Digit Keypad

ปรับปรุงจาก V4.27:
- กรอกเลขออกจริง 3 หลักครบแล้ว ไปช่องเลข 2 ตัวอัตโนมัติ
- กรอกเลขออกจริง 2 ตัวครบแล้ว ปิดแป้นตัวเลขทันที ไม่ต้องกด DONE
- เลื่อนหน้าฟอร์มไปยังปุ่ม Save เลขออกจริงอัตโนมัติ
- ยังต้องกด Save เพื่อยืนยัน ป้องกันการบันทึกเลขผิดโดยไม่ตั้งใจ
- ระบบ One-Tap Date Picker, History และสร้างตารางอัตโนมัติยังคงเดิม
