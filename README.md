# LuckyNumber V4.33 — Real-time Profile Ranking

เพิ่มอันดับ Profile จากสถิติย้อนหลังแบบอัตโนมัติในหน้า Analysis

- สลับโหมด “ตามที่จัดเอง” และ “ตามคะแนนล่าสุด”
- Exact = 1 คะแนน, Reversed = 0.6 คะแนน
- น้ำหนัก 10 งวดล่าสุด 50%, 30 งวดล่าสุด 30%, ข้อมูลทั้งหมด 20%
- กดรายการอันดับเพื่อเปิดสถิติ Profile นั้นทันที
- อัปเดตทันทีเมื่อบันทึกหรือแก้ไขผลจริง
- ลำดับหลักในหน้าอื่นยังคงตามที่ผู้ใช้จัดไว้

หมายเหตุ: คะแนนเป็นสถิติย้อนหลัง ไม่ใช่การรับประกันผลในอนาคต
