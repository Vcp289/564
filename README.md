# LuckyNumber V4.39 — AI Web Sync

ต่อยอดจาก V4.38 โดยเพิ่มเฉพาะ Tab AI:
- AI Data Center แยกจำนวนข้อมูลจากแอป / เว็บ / ทั้งหมด
- ปุ่ม Sync เว็บผ่าน JSON/API ที่อนุญาต CORS
- ปุ่มนำเข้าไฟล์ JSON เป็นทางสำรอง
- บันทึกผล 3 ตัวและ 2 ตัวเข้า History อัตโนมัติ
- สร้างตารางงวดถัดไปและคำนวณ History L อัตโนมัติ
- ป้องกันข้อมูลซ้ำตาม Profile + วันที่
- ไม่เขียนทับผลที่ผู้ใช้กรอกเองเมื่อวันที่ซ้ำ
- เก็บสถานะและเวลาที่ Sync ล่าสุด

รูปแบบ JSON ที่รองรับ:
```json
[
  {"date":"2026-08-05","number":"123","twoDigit":"45"}
]
```
หรือวาง Array ไว้ใน `results`, `data` หรือ `draws`

หมายเหตุ: เว็บผลหวยทั่วไปมักไม่อนุญาตให้ PWA ดึงหน้าเว็บโดยตรง (CORS) จึงควรใช้ API/JSON endpoint ของเราเอง หรือดาวน์โหลด JSON แล้วใช้ปุ่มนำเข้า
