# LuckyNumber V4.19 — Browse Result Calendar

อัปเดตต่อจาก V4.18 โดยแก้เฉพาะหน้า Calculate:
- คงปุ่ม LOAD LAST RESULT สำหรับเรียกข้อมูลล่าสุด
- เพิ่มปุ่ม BROWSE HISTORY เพื่อเลือกผลย้อนหลังจากปฏิทิน
- ปฏิทินแสดงเฉพาะข้อมูลของชื่อ/ประเทศที่เลือก
- วันที่มีเลขออกจริง 3 ตัวและ 2 ตัวครบจะไฮไลต์สีน้ำเงิน
- แตะวันที่แล้วนำ 3 ตัวใส่ช่อง 1–3 และ 2 ตัวใส่ช่อง 4–5
- คำนวณตาราง 15 ช่องอัตโนมัติหลังเลือกวันที่
- วันที่ไม่มีข้อมูลหรือวันที่อนาคตกดไม่ได้
- ไม่แก้โครงสร้าง Weekly, History, Analysis และ Settings
