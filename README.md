# LuckyNumber V4.31 – Profile Reorder Fix

ปรับการสลับลำดับ Profile ให้ใช้งานได้แน่นอนบน iPhone

- เพิ่มปุ่ม ▲ และ ▼ สำหรับเลื่อน Profile ขึ้นหรือลงทีละอันดับ
- ยังคงกดค้างที่ ☰ เพื่อลากเรียงลำดับได้
- ลำดับใหม่ถูกใช้ร่วมกันใน Calculate, Weekly, History, Analysis และ Settings
- ชื่อ ตาราง ผลจริง และ History ของ Profile ย้ายตามกันทั้งชุด
- ปัดซ้ายเพื่อลบ Profile ได้เหมือนเดิม

ให้อัปโหลดไฟล์ทั้งหมดทับเวอร์ชันเดิมบน GitHub Pages
