# LuckyNumber V4.27 — One-Tap Date Picker

ปรับปรุงจาก V4.26:
- ช่องวันที่ในหน้าบันทึก/แก้ไขเลขออกจริง เปิดปฏิทินด้วยการแตะครั้งเดียวบน iPhone
- เรียก native date picker จาก user gesture โดยตรง พร้อม fallback สำหรับเบราว์เซอร์ที่ไม่มี showPicker()
- ป้องกัน event ของ modal แย่งการแตะช่องวันที่
- ยกเลิกการ focus ช่องเลข 3 หลักอัตโนมัติเมื่อเปิดฟอร์ม เพื่อไม่ให้รบกวนการเลือกวันที่ย้อนหลัง
- ระบบบันทึกผลจริง อัปเดต History และสร้างตารางอัตโนมัติจาก V4.26 ยังคงเดิม
