# LuckyNumber V4.34 — Analysis Profile Tabs Ranking Fix

แก้ไขหน้า Analysis ให้ปุ่ม Profile ด้านบนเปลี่ยนลำดับตามโหมดที่เลือกจริง

- เลือก “ตามคะแนนล่าสุด” → ปุ่ม Profile ด้านบนเรียงจากคะแนนสูงไปต่ำทันที
- เลือก “ตามที่จัดเอง” → กลับไปใช้ลำดับจากหน้า Settings
- Profile ที่กำลังเลือกยังคง active และข้อมูลไม่สลับผิด Profile
- สีประจำ Profile และข้อมูลทั้งหมดคงเดิม
- Calculate, Weekly และ History ยังคงลำดับที่ผู้ใช้จัดเอง

## V4.38 Safe AI Formula Activation
- สูตรดั้งเดิมเก็บถาวร ลบไม่ได้ และย้อนกลับได้ตลอด
- สูตร AI เริ่มเป็นสูตรทดลอง ไม่กระทบหน้า Calculate
- ทดลองสูตร AI กับเลขปัจจุบันได้ครั้งเดียว

- แสดงสูตรที่กำลังใช้งานในหน้า Calculate และ AI
- ตารางที่บันทึกใหม่เก็บ formulaMode และ formulaSnapshot
