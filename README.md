# LuckyNumber V4.32 – Clean Drag Reorder

ปรับหน้า Settings ราย Profile ให้เหมือนรายการเรียงลำดับแบบ iOS

- เอาปุ่มสามเหลี่ยม ▲ ▼ ออกทั้งหมด
- เอาข้อความ Profile 1, Profile 2 ออก เหลือชื่อ Profile โดยตรง
- ย้ายปุ่ม ☰ ไปด้านขวาของแต่ละแถว
- กดค้างที่ ☰ แล้วลากขึ้นลงเพื่อสลับลำดับ
- ลำดับใหม่ใช้ร่วมกันทุกหน้า Calculate, Weekly, History, Analysis และ Settings
- ปัดแถวไปทางซ้ายเพื่อลบ Profile ได้เหมือนเดิม
- ข้อมูล ตาราง ผลจริง และ History ของแต่ละ Profile ย้ายตามทั้งชุด

ให้อัปโหลดไฟล์ทั้งหมดทับเวอร์ชันเดิมบน GitHub Pages
