# LuckyNumber V5.4 Image Import

พัฒนาต่อจาก V5.3 โดยคงฟีเจอร์เดิมทั้งหมด และเพิ่ม:
- ปุ่ม “นำเข้าจากรูป” ในหน้า History > ผลย้อนหลัง
- เลือกภาพหน้าจอ/ภาพถ่ายได้หลายรูปในครั้งเดียว
- OCR ภาษาไทยและอังกฤษ อ่านวันที่, เลข 3 ตัวบน และเลข 2 ตัวล่าง
- หน้าตรวจสอบและแก้ไขก่อนบันทึก
- เลือกข้ามหรือแทนที่ข้อมูลวันที่ซ้ำ
- อัปเดต History, ตาราง, Auto L และ AI หลังยืนยัน
- สำรองข้อมูลอัตโนมัติตามการตั้งค่าเดิม

ข้อกำหนด: การอ่าน OCR ครั้งแรกต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Tesseract.js และชุดภาษาไทย ภาพควรคมชัด เห็นวันที่ เลข 3 ตัว และเลข 2 ตัวในแถวเดียวกัน
