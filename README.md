# LuckyNumber V4.29 — Profile Reorder & Swipe Delete

ปรับปรุงจาก V4.28:
- กดค้างที่ ☰ แล้วลาก Profile ขึ้นหรือลงเพื่อเปลี่ยนลำดับ
- ลำดับใหม่เชื่อมโยงกับ Calculate, Weekly, History และ Analysis ทั้งหมด
- ปัดแถว Profile จากขวาไปซ้ายเพื่อแสดงปุ่มลบสีแดงแบบ iOS
- ลบเฉพาะ Profile พร้อมตาราง ผลจริง และ History ของ Profile นั้น
- ป้องกันการลบ Profile สุดท้าย และมีหน้าต่างยืนยันก่อนลบ
- ข้อมูล profileId ถูกปรับลำดับใหม่เพื่อไม่ให้ข้อมูลข้าม Profile
- ฟีเจอร์เดิมของ V4.28 ยังคงอยู่ครบ
