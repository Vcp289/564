# LuckyNumber Pro V4

ฟีเจอร์หลัก
- คำนวณตาราง 3×5 จากเลขตั้งต้น 5 ตัว
- หาเลข L จำนวน 24 ตำแหน่ง โดยไม่นับคอลัมน์ที่ 5
- แตะชุด L เพื่อดูตำแหน่ง ทิศทาง และไฮไลต์บนตาราง
- บันทึกผลตรง / สลับ / ไม่พบ พร้อม Pattern ID อัตโนมัติ
- บันทึกแยก 5 ชื่อ และตารางจันทร์–อาทิตย์
- ประวัติย้อนหลัง, Pattern Ranking, Heat Map และคะแนนสถิติ
- สำรอง/นำเข้าข้อมูล JSON และใช้งานแบบ PWA ออฟไลน์

## GitHub Pages
อัปโหลดไฟล์ทั้งหมดไว้ที่ root ของ repository จากนั้นไปที่ Settings > Pages > Deploy from a branch และเลือก main / root.
